## 项目概览

### 功能范围

| 类别 | 实现内容 |
| --- | --- |
| 多通道采集 | 温湿度 / 气压 / 光照 / 三轴加速度，统一采集周期与时间戳对齐 |
| 实时系统 | FreeRTOS 多任务划分，队列传递数据、互斥量保护共享 I2C 总线 |
| 本地交互 | LVGL 图形界面：实时数值 + 历史曲线 + 参数设置 |
| 无线上报 | ESP32-C3 通过 MQTT 上报，支持断线重连与本地缓存补传 |
| 上位机 | Python `pyserial` 实时绘图，CSV 落盘，支持参数下发 |

### 技术栈

`STM32F407` · `FreeRTOS` · `HAL + LL` · `LVGL` · `I2C / SPI / UART / DMA` · `ESP32-C3` · `MQTT` · `CMake + Ninja + GCC` · `Python`

### 完整链路

```
原理图设计 → PCB Layout → 焊接与硬件调试 → BSP 与驱动编写 → RTOS 应用层 → 上位机
```

全部由本人独立完成，而非使用成品开发板拼凑 —— 这也是本项目与常见课程设计的主要区别。
